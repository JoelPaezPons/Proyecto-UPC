Proyecto Satélites UPC 
Este proyecto consiste en el diseño y desarrollo de una plataforma web integral para los alumnos de la UPC (Universitat Politècnica de Catalunya). El portal está dedicado a la difusión y gestión de sus proyectos de satélites, permitiendo centralizar la información técnica y facilitar la interacción de los usuarios con los datos de las misiones.

Desarrollado en colaboración por un equipo de 5 estudiantes, integrando tecnologías modernas para ofrecer una experiencia robusta y escalable.

Funcionalidades Principales
Gestión de Satélites: Visualización detallada de información sobre los proyectos espaciales de la universidad.

Favoritos Personalizados: Sistema de persistencia en base de datos que permite a los usuarios registrados guardar y gestionar sus satélites favoritos.

Portal Informativo: Secciones dedicadas a los equipos de ingeniería responsables de los satélites y a los desarrolladores de la web.

Arquitectura Desacoplada: Comunicación fluida entre un frontend dinámico y una API RESTful.

🛠️ Stack Tecnológico
Frontend: Angular (Framework de TypeScript para una SPA dinámica).

Backend: Laravel (Framework PHP para la API y lógica de negocio).

Base de Datos: MySQL (Gestionada a través del servidor académico proporcionado en clase).

Servidor: Despliegue en entorno de pruebas académico.

Estructura del Proyecto
/frontend: Contiene la aplicación Angular (componentes, servicios de conexión a la API y estilos).

/backend: Contiene la lógica de Laravel (rutas API, controladores, modelos de Eloquent y migraciones).
