Sobre el Proyecto

Satélite simulado

El satélite simulado representa un sistema embarcado basado en Arduino que se encarga de la recogida de datos y la captura de imágenes. Está equipado con sensores de temperatura, humedad y distancia, así como con una cámara digital, lo que le permite simular las funciones básicas de un satélite de observación.


Este sistema transmite la información recopilada a la estación de tierra mediante comunicación inalámbrica LoRa, utilizando protocolos que garantizan la integridad de los datos. Además, es capaz de recibir comandos desde tierra, simulando el control remoto de un satélite en órbita.

Estación de Tierra

La estación de tierra es el sistema encargado de recibir, procesar y visualizar la información enviada por el satélite simulado. A través de una interfaz gráfica desarrollada en Python, permite al usuario monitorizar datos ambientales, observar la posición orbital del satélite y gestionar la captura de imágenes.


Además, la estación de tierra actúa como centro de control, ya que envía comandos al satélite para modificar su comportamiento, como ajustar la toma de datos o iniciar la captura de imágenes. De este modo, simula el funcionamiento real de una estación terrestre de control satelital.

Herramientas y Tecnologías

Arduino

Plataforma utilizada como base del sistema satelital. Permite conectar sensores, la cámara y los módulos de comunicación, ejecutando el código que controla la captura y transmisión de datos.

LoRa

Tecnología de comunicación inalámbrica de largo alcance y bajo consumo. Se utiliza para transmitir datos e imágenes entre el satélite y la estación de tierra, simulando un enlace satelital real.

Librerías de Python

Conjunto de librerías utilizadas para el procesamiento y visualización de datos. Permiten generar gráficos, representar la órbita del satélite, gestionar imágenes y facilitar la comunicación con el hardware.

Python

Se utiliza para desarrollar la estación de tierra y la interfaz gráfica. Permite recibir y procesar los datos del satélite, visualizar la órbita y los sensores, y gestionar la captura y visualización de imágenes.

C

Se utiliza para programar el Arduino del satélite y la estación de tierra. Controla los sensores, la cámara y la comunicación LoRa, gestionando la captura y el envío de datos de forma eficiente.
